# Taichi — dependencias del frontend
#
# Este archivo es una referencia legible para mantener el inventario de
# dependencias. La instalación reproducible se hace con package-lock.json:
#
#   npm install
#
# Requisitos de desarrollo local: Docker Desktop (incluye Docker Compose) y
# Node.js 22.12+. Para crear PostgreSQL, migrar el esquema y cargar las
# rutinas iniciales ejecuta `npm run db:setup`.
#
# Para instalar manualmente desde esta lista, ejecuta los dos comandos npm
# que aparecen abajo. Mantén package.json y este archivo sincronizados cuando
# agregues o elimines una dependencia.
